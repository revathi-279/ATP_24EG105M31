# Week-2 JavaScript Array Methods & Modular Projects

## Overview

Week-2 focused on strengthening JavaScript fundamentals and advancing toward real-world application development using:

- Higher-order array methods
- Object manipulation
- ES6 modules
- OOP concepts
- Asynchronous JavaScript
- Modular system design

The assignments were built around real-life scenarios such as:

- Weather analysis
- Student result systems
- Shopping cart systems
- Payroll processing
- Movie recommendation systems
- Banking transaction analysis
- Task management applications
- E-Commerce store simulation
- Library management system
- OTP and exam simulation systems

This week significantly improved problem-solving skills and introduced modular programming using JavaScript ES6 architecture.
