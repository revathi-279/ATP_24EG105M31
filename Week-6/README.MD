
## Overview

This week focused on building practical React and MERN Stack applications by combining frontend development, backend APIs, database integration, and modern React concepts.

The projects were designed to strengthen understanding of:

* React component architecture
* State management
* Props and Context API
* Form handling
* CRUD operations
* REST APIs
* MongoDB integration
* Frontend and backend connectivity

The week included multiple mini-projects and a complete full-stack Employee Management System.

---

# Projects Included

## 1. Counter Project

A shared counter application built using React Context API.

### Features

* Shared global counter state
* Increment and decrement functionality
* Multiple components updating the same state
* Context API implementation
* Reusable counter components
* Tailwind CSS UI styling

### Concepts Practiced

* `useContext`
* Context API
* Global state management
* Functional components
* Component reusability

---

## 2. User Count Project

A simple React application demonstrating state lifting and prop drilling.

### Features

* Add user count dynamically
* Shared count state across components
* Event handling using buttons
* Real-time UI updates

### Concepts Practiced

* `useState`
* Props
* Parent-to-child communication
* Event handling
* Component rendering

---

## 3. User Table Project

A dynamic form and table rendering project using `react-hook-form`.

### Features

* Create user form
* Add users dynamically into a table
* Form reset after submission
* Display user information in tabular format
* Dynamic list rendering

### Concepts Practiced

* `react-hook-form`
* Form handling
* Array state management
* Rendering lists using `.map()`
* Dynamic UI updates
* Table rendering

# 4. Employee Management System (Full Stack MERN Project)

A complete MERN Stack CRUD application for managing employee records.

## Frontend Features

* Create employee
* View employee details
* Edit employee information
* Delete employee records
* Dynamic routing
* Responsive UI using Tailwind CSS
* Navigation using React Router
* API integration using Fetch and Axios

## Backend Features

* REST API development using Express.js
* MongoDB database integration
* Employee schema creation using Mongoose
* CRUD API endpoints
* CORS configuration
* Environment variable management using dotenv

# Technologies Used

## Frontend

* React.js
* React Router
* React Hook Form
* Axios
* Tailwind CSS

## Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
