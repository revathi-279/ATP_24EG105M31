## Overview

This project contains a collection of beginner-friendly HTML webpages created to practice fundamental web development concepts.
The webpages demonstrate the use of basic HTML elements including headings, paragraphs, lists, images, links, formatting tags, and nested structures.

The project is designed for learning and understanding the core structure of HTML documents.

---

# Included HTML Files

## 1. BasicWebPage.html

This webpage demonstrates the use of:

* Basic HTML document structure
* Paragraphs
* Headings
* Bold and italic text formatting
* Hyperlinks
* Unordered lists

### Concepts Practiced

* `<html>`
* `<head>`
* `<body>`
* `<p>`
* `<h1>`
* `<b>`
* `<i>`
* `<a>`
* `<ul>`
* `<li>`

### Functionality

The page contains introductory text, formatted content, a clickable Google link, and a list of fruits.

---

## 2. NestedLists.html

This webpage demonstrates nested unordered lists.

### Concepts Practiced

* Nested lists
* Parent and child list relationships
* List organization

### HTML Elements Used

* `<ul>`
* `<li>`

### Functionality

The page displays categorized items including:

* Fruits
* Vegetables
* Cereals
* Nuts

with sub-items under Fruits and Vegetables.

---

## 3. Cat.html

This webpage is a profile page for a fictional cat named Chichu.

### Concepts Practiced

* Image embedding
* Ordered lists
* External links
* Horizontal rules
* Structured content sections

### HTML Elements Used

* `<img>`
* `<ol>`
* `<ul>`
* `<a>`
* `<hr>`
* `<div>`

### Functionality

The webpage includes:

* A cat image
* Introduction section
* Profile information
* Hobbies and talents
* External links related to cats
* Footer-style update information
